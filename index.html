2. Принцип локальной работы

Приложение предназначено для офлайн-чтения, просмотра искусства, исследования и учебной игры. Оно не создаёт аккаунт, не содержит рекламных или аналитических SDK и не запрашивает разрешение INTERNET. Разработчик не получает автоматически сведения о пользователе, его чтении, конфессиональном выборе или заметках.

3. Какие сведения хранятся на устройстве и зачем

Язык интерфейса, выбранный исследовательский конфессиональный контекст, перевод Библии, тема, размер текста и интерес сохраняются для персональной настройки. Последняя глава, закладки, личные заметки, исследовательские досье, отметки изучения и просмотренные игровые карточки сохраняются для продолжения работы. Религиозный выбор может быть чувствительной информацией: его указание необязательно, можно оставить общехристианский обзор. Он не передаётся разработчику и не используется для рекламного профилирования.

4. Сроки хранения и удаление

Локальные данные остаются до удаления пользователем. Заметки можно удалить в библиотеке, профиль и настройки — изменить в «Моём пути» и настройках. Для удаления всех локальных данных используйте очистку хранилища приложения в настройках Android или удалите приложение. Экспортированные пользователем копии удаляются отдельно через файловый менеджер либо выбранного облачного провайдера. Разработчик не имеет доступа для удалённого удаления локальных копий.

5. Экспорт, импорт и резервные копии

JSON v2 содержит заметки, досье, закладки и прогресс, но не настройки, изображения и историю. Файл не зашифрован. Пользователь сам выбирает место записи системным файловым диалогом; выбранный провайдер может быть облачным и действовать по собственной политике. Не отправляйте копии с личными или религиозными сведениями посторонним. Приложение не использует автоматическую облачную резервную копию Android; системный перенос зависит также от платформы и устройства.

6. Внешние ссылки и обращения в поддержку

Музейные, церковные и справочные ссылки открываются только по действию пользователя во внешнем приложении. Браузер и сайт могут получать сетевые данные по своим политикам. Письмо в поддержку отправляется только самим пользователем через его почтовую программу; приложение не прикладывает заметки или настройки автоматически. Для ответа используются только сведения, добровольно включённые в обращение. Если отправитель просит удалить переписку, запрос рассматривается через контакт выше с учётом законных обязанностей хранения. Не направляйте ненужные чувствительные сведения.

7. Защита и ограничения

Данные находятся в закрытом каталоге приложения Android, но приложение не обещает отдельного шифрования своих БД. Используйте блокировку экрана и безопасное хранение резервных копий. Лицензия разработчику не передаёт права на личные заметки пользователя. Приложение не оценивает веру и не заменяет духовное руководство или экспертизу.

8. Изменения

При изменении состава собираемых или передаваемых сведений политика должна быть обновлена до выпуска соответствующей версии. Настоящий текст относится к сборке без аккаунтов, аналитики, рекламы и сетевых сервисов внутри приложения.

9. Локальные уведомления календаря Уведомления выключены по умолчанию. По явному действию пользователя сохраняются на устройстве выбранное время и режим: ежедневный обзор либо напоминание о Пасхе и двунадесятых праздниках. Разрешение POST_NOTIFICATIONS запрашивается на Android 13 и новее только при включении. RECEIVE_BOOT_COMPLETED используется для восстановления выбранного расписания после перезагрузки; также учитываются изменения времени, часового пояса и обновление приложения. Интернет, серверные push-уведомления и аккаунт не используются. Android может задерживать доставку при экономии энергии; точное время не гарантируется. Напоминания можно выключить в разделе «Календарь» либо запретить в настройках Android. Очистка данных приложения удаляет настройки напоминаний. На закрытом экране используется нейтральная публичная версия уведомления; видимость зависит также от настроек Android. При открытии уведомления показан календарь. Религиозные сведения из календаря и выбранное расписание не передаются разработчику.

10. Публичная веб-страница политики

При самостоятельном открытии политики на GitHub или GitHub Pages браузер обращается к GitHub. GitHub может получать IP-адрес и технические сведения по своей политике: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement . Это отдельное посещение сайта, а не фоновая отправка данных приложением. На самой подготовленной странице нет аналитики, внешних шрифтов, рекламных скриптов и формы сбора данных.
